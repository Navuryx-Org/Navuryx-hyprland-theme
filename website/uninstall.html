Complete removal

One command removes Navuryx.

The default uninstaller removes every file, application, dependency, helper and Flatpak item that Navuryx recorded as newly installed, restores the previous desktop when available, then deletes Navuryx state and backups.

Remove everything

Complete uninstall
./uninstall.sh

Use ./uninstall.sh --yes to skip the confirmation.

What gets removed

Navuryx removes its configuration, selected applications, dependencies, Yay or Paru when Navuryx installed them, Flatpak items added by Navuryx, MicroTeX, Navify installed for Spotify, logs, manifests and backups. The newest pre-Navuryx configuration is restored first when available.

Packages that already existed before Navuryx are not recorded and are not removed.

Keep selected parts

Examples
./uninstall.sh --keep-installed-apps
./uninstall.sh --keep-dependencies --keep-helpers
./uninstall.sh --keep-backups --no-restore

Failed or partial installs

The uninstaller reads both complete and partial package records and uses exact Navuryx-owned paths when the main manifest was never finalized.
