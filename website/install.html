Installation guide

Install Navuryx without losing your current desktop.

The installer creates a timestamped backup before activating configuration. Package work happens first, so a dependency failure does not replace your active Hyprland setup.

Quick install

Terminal
git clone https://github.com/navuryx-org/navuryx-hyprland-theme.git
cd navuryx-hyprland-theme
chmod +x install.sh uninstall.sh navuryx
./install.sh
Back up important personal files. Navuryx creates its own configuration backup, but a separate personal backup is still good practice before changing a desktop environment.

What the installer does
  1. Checks Arch/Pacman compatibility, disk space and required commands.
  2. Shows Full, Custom, Recovery and configuration-only profiles.
  3. Lets you select browsers, Discord clients, VPN tools, development tools, media apps and creator apps.
  4. Installs Yay when missing. Paru and Flatpak remain optional.
  5. Installs required AI and gaming foundations for the Full profile.
  6. Stages configuration, creates a backup and activates Navuryx.
  7. Writes managed-file and package manifests for repair and removal.


Password prompts
Expected: your local Linux password may be requested by sudo to install system packages.
Not expected: the installer never requests a GitHub username, GitHub password or access token. Git downloads run with interactive credential prompts disabled. An unavailable public repository fails with an error instead.

After installation
Log out and start a Hyprland session. Keep the repository directory until you have verified the desktop because it contains the repair and uninstall scripts.
Check the installation
./install.sh --verify
navuryx doctor


Spotify integration
Selecting Spotify also installs the public Navify CLI release automatically. Navify is installed to ~/.local/bin/navify; no GitHub credentials are requested.
