Troubleshooting

Recover first. Debug second.

The installer and uninstaller preserve logs and backups so failures do not have to become a blank desktop.

Git asks for a username or password

Navuryx does not require GitHub credentials. Cancel the prompt with Ctrl+C, update to the current installer and run it again.

A public dependency URL that returns 404 can sometimes be mistaken for a private repository by Git. Current Navuryx releases disable interactive Git credentials and use the verified public MicroTeX source.

Installation failed before configuration activation

Run the uninstaller normally. It reads the partial package record and removes any exact Navuryx-owned files that were created.

Cleanup
./uninstall.sh

Hyprland starts to a blank desktop

  1. Switch to another TTY with Ctrl+Alt+F3.
  2. Log in.
  3. Restore the previous configuration.
Restore
cd navuryx-hyprland-theme
./uninstall.sh --restore-latest

Uninstall did not remove everything

Use the current repository copy. The updated uninstaller handles files under ~/.local/share/navuryx, old manifests and partial installations.

Full Navuryx cleanup
./uninstall.sh --restore-latest --purge

Logs and state

  • Installer state: ~/.local/state/navuryx/
  • Backups: ~/.local/state/navuryx/backups/
  • Uninstall logs: ~/.local/state/navuryx/logs/
  • Managed file list: ~/.local/state/navuryx/managed-files.txt
  • Partial package record: ~/.local/state/navuryx/partial-installed-packages.tsv
