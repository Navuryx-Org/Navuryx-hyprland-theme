Feature map

One shell, one installer, one recovery path.

Navuryx combines desktop UI, system controls, app selection and lifecycle tools under a consistent command and design system.

Desktop shell

Top bar, dock, Spotlight, overview, task view, sidebars, notifications, OSD, lock and session surfaces.

System integration

Audio, media, Wi-Fi, Bluetooth, brightness, power, VPN, gaming and update controls.

Application setup

Multi-select browsers, communication clients, VPN tools, development software, media and creator apps. Spotify automatically includes Navify CLI.

AI tools

Local-first Ollama foundation, provider configuration, OCR, screen-region capture and assistant workflows.

Theming

Black, royal-blue and purple defaults with wallpaper-aware colors and shared application templates.

Recovery

Waybar/Rofi fallback, diagnostics, managed-file manifests, backups, repair and safe removal.

Status

Feature maturity is visible.

Hardware and provider-dependent integrations can vary by system. The project documents that instead of pretending every module behaves identically everywhere.
